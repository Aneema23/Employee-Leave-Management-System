🧾 Employee Leave Management System (C#)

📘 Overview
The Employee Leave Management System is a C# application designed to simplify and automate the process of managing employee leave requests within an organization. It enables administrators to efficiently handle leave records, approve or reject requests, and maintain an accurate leave history for all employees.


⚙️ Features

👩‍💼 Employee Management: Add, update, and delete employee records.

📅 Leave Request System: Employees can apply for leave, specifying leave type and duration.

🕒 Leave Approval Workflow: Admins can view, approve, or reject leave requests.

📊 Leave Tracking: View leave balance, leave history, and pending requests.

🔒 User Authentication: Secure login system for employees and administrators.

💾 Database Integration: Stores all data using a relational database (e.g., SQL Server).


🛠️ Technologies Used

Programming Language: C# (.NET Framework / .NET Core)

Database: Microsoft SQL Server

IDE: Visual Studio

UI Framework: Windows Forms / WPF (depending on your implementation)



🚀 How It Works

Login: Employees and admins log into the system.

Employee Actions: Employees submit leave requests and check approval status.

Admin Actions: Admins manage employee data and review leave applications.

Database Operations: All data is stored securely in the database for future reference.



📈 Benefits

Reduces manual paperwork.

Improves accuracy in leave tracking.

Enhances transparency between employees and management.

Provides a user-friendly interface for both staff and admin.
